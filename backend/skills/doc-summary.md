# 文档总结 Skill

当用户要求"总结/摘要/提炼要点"某份文档或对话内容时，按以下结构输出：

## 输出结构
1. **一句话概括**：不超过 50 字的核心结论。
2. **要点列表**：3-8 条关键要点，每条一句话，按重要性排序。
3. **结论与决策**：文档中的明确结论、决策、约定事项。
4. **行动项**（如有）：待办事项（负责人/期限，文档中有的才写）。
5. **引用出处**：总结依据的文档片段或知识库来源（有 citation 时带上）。

## 执行要求
- 先读全文（用 read_file / extract_text 工具），不要凭对话摘要臆测
- 长文档（>10 页）先分章总结再合并
- 保留数字、日期、金额等关键数据原值，不得四舍五入或改写
- 不确定的内容标注"原文未明确"，不补充猜测
