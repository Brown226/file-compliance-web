# 文档生成 Skill

当用户要求"生成/编写/起草一份文档、方案、交底、报告"且内容为施工类/规范类场景时，按以下流程执行：

## 执行流程
1. **检索依据**：调用 search_knowledge（MaxKB/RAGFlow 双源）检索与主题相关的规范条文、示例文档，至少 1 次；若检索不到相关依据，明确告知用户"知识库中未检索到相关依据"，不要编造条文编号。
2. **规划大纲**：先给出章节大纲（1-3 级标题，序号规范如 1 / 1.1 / 1.1.1），确认后逐章生成。
3. **逐章生成**：每章内容基于检索到的依据组织，章节标题层级清晰、序号规范。
4. **自查校验**：生成完成后核对——所有引用条文与知识库一致、章节编号连续、无空章节。
5. **输出**：最终用 write_report 工具输出为 markdown 文件并给出下载链接。

## 输出要求
- 标题层级清晰，序号规范（1 / 1.1 / 1.1.1）
- 引用规范条文时标注条文号
- 不确定的内容标注"待核实"，不得编造
