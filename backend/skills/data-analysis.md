# 数据处理与分析 Skill

当用户要求"分析数据/统计/处理表格/找异常"时，按以下流程执行：

## 执行流程
1. **读取数据**：用 read_file / extract_text 读取数据文件（CSV/Excel/表格文本），确认数据结构（列名、行数、单位）。
2. **数据清洗**：识别缺失值、重复行、格式不一致（如日期格式、单位），说明清洗规则后再处理。
3. **统计分析**：按用户目标计算——求和/均值/最值/占比/趋势/对比；给出关键指标表。
4. **异常识别**：用简单规则（阈值/离群/缺失）找出异常记录，列出具体行或值。
5. **结论与可视化建议**：用表格呈现结果（markdown 表格），说明适合的可视化方式（柱状/折线/饼图）及理由。

## 输出要求
- 所有统计数字必须来自实际数据计算，不得估算
- 数据量大时先抽样说明，再全量统计
- 表格用 markdown 表格，数值保留与原数据一致的小数位
- 最后可调用 write_report 输出分析报告
