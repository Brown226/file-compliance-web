## 一、智能审查页面 (/review) - 核心改进

### 1.1 参考项目亮点

```
✅ Hero Section: 大幅背景图 + 半透明遮罩 + 清晰CTA
✅ 三步流程: 上传 → 确认范围 → 查看结果
✅ 预审功能: AI识别文件类型 → 用户确认立场/审查点 → 开始分析
✅ 多文件关联: 支持主合同+附件+补充协议对比分析
✅ 实时进度: 显示"提取文本→搜索法规→验证条款→生成结论"
```

### 1.2 当前系统现状

```
❌ 无Hero引导区,页面平淡
❌ 上传后直接开始审查,无确认步骤
❌ 缺少立场选择和审查点自定义
❌ 无多文件对比功能
❌ 进度反馈不够详细
```

#### **关键改进点**

1. **Hero Section设计**
   - 背景: 使用渐变色 `linear-gradient(135deg, #667eea 0%, #764ba2 100%)` 或行业相关图片
   - 高度: 280px
   - 内容: Logo + 主标题 + 副标题 + 四步流程图标
   - CTA按钮: "开始审查" (白色背景, 蓝色边框)

2. **步骤条优化**
   - 固定在页面顶部
   - 当前步骤: 蓝色圆圈 + 白色数字
   - 已完成: 绿色圆圈 + 白色对勾
   - 未完成: 灰色圆圈 + 灰色数字
   - 连接线: 蓝色(已走路径) / 灰色(未走路径)

3. **上传区域增强**
   - 拖拽区: 虚线边框 + 大图标(64px) + 明确提示
   - 悬停效果: 边框变蓝 + 背景变浅蓝
   - 文件列表: 显示文件类型图标 + 文件名 + 大小 + 删除按钮
   - DWG文件: 显示缩略图预览(利用现有DwgPreview组件)

4. **预审确认页面** (重点借鉴参考项目)
   - 文件类型识别: AI初步识别后显示
   - 立场选择: 下拉选择(建设方/施工方/监理方/设计方)
   - 标准选择: 多选复选框, 显示已启用标准
   - 审查点选择: 标签式多选, 默认全选
   - 核心目的: 自动补全输入, 支持自定义添加

5. **进度展示优化**
   - 步骤式进度条: 显示每个阶段的完成状态
   - 时间估算: 显示预计剩余时间
   - 实时日志: 可展开查看详细日志
   - 后台运行: 支持最小化到任务列表

#### **关键改进点**

1. **Tab导航设计** (参考项目核心亮点)
   - **审查明细**: 逐条显示问题, 支持筛选/搜索/操作
   - **问题汇总**: 按类别/严重度分组统计
   - **原文预览**: 显示文件原文, 支持高亮问题位置
   - **统计分析**: ECharts图表展示问题分布

2. **问题卡片优化**
   - 左侧边框颜色区分严重度(红/橙/蓝)
   - 顶部: 规则代码 + 分类标签 + 严重度徽章
   - 中间: 原文引用(浅灰背景, 等宽字体)
   - 底部: 建议修改(绿色文字) + 操作按钮
   - 悬停效果: 阴影加深 + 边框高亮

3. **大白话模式** (参考项目特色)
   - Switch开关切换
   - 开启后: 专业术语替换为通俗解释
   - 背景色: 蓝色/绿色提示框
   - 示例: 
     - 专业: "页眉编码不一致"
     - 大白话: "文档顶部的编号和封面对不上哦"

4. **文本对比预览**
   - 采纳建议后显示
   - 左右对比: 采纳前(红色背景) vs 采纳后(绿色背景)
   - 支持一键复制到剪贴板
   - 支持撤销操作

5. **操作按钮增强**
   - **定位**: 在原文中高亮显示问题位置
   - **采纳**: 接受AI建议, 更新文档
   - **误报**: 标记为误报, 加入误报库
   - **忽略**: 暂时忽略, 不计入统计
